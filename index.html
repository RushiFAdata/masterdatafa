Master Pricing ID Mapping

Matches distributor and product IDs against two mapping files and adds the corresponding ID to every row, flags everything that cannot be matched, and exports a consolidated pricing file. Every original column and value is carried through unchanged, and nothing is dropped. Runs entirely in your browser.

1

Load the three files

Excel (.xlsx, .xls) or CSV. Drag onto a box or choose a file.

File A — required
Master pricing
A distributor ID, a product ID, and all pricing columns
File B — required
Distributor mapping
Both distributor IDs, in either order
File C — required
Product mapping
Both product IDs, in either order
2

Confirm the columns

Pre-filled by checking which column in each mapping file actually holds the same IDs as your master file — not by column name, so it works whichever way round your files are. Change anything that looks wrong.

All IDs are read as text, so leading zeros survive. Pricing values are copied through exactly as they appear in the source — nothing is rounded or reformatted. Matching ignores surrounding spaces and letter case, while the output keeps the original spelling. Records that cannot be matched stay in the file with a status against them.
